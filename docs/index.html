Why ClipStash?

⚡

Search recent copies

Find text in your local history and preview copied images before you reuse them.

📌

Pin and filter

Pin useful clips and filter the history by source app.

📤

Export to a folder

The current source can export pinned clips or filter by source app. The Markdown or plain-text export can include a folder of separate image files.

Clipboard history stays on your Mac

  • No built-in account, cloud sync, or usage analytics
  • Configure excluded apps and sensitive clipboard type filters
  • Review your history and exported files before sharing them

From clips to a project note
